# Changelog

## 1.0.0 - 2026-08-23

- Add SMTP transport registration for Jyavani Core Mail API 2.3.82.
- Add implicit TLS, STARTTLS, AUTH PLAIN, AUTH LOGIN, and trusted unauthenticated relay support.
- Enforce TLS 1.2+, certificate/hostname verification, and optional private CA files.
- Add Sodium-encrypted credential storage and Site Owner-only settings.
- Add conservative retry classification to prevent ambiguous duplicate delivery.
- Add responsive light/dark dashboard interface and Indonesian/German translations.
- Add protocol, security, configuration, and package contracts.
